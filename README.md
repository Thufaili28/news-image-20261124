# Sum up 24 November's world news in one image

Entry for make.fun bounty `news-image-20261124`.

Run:

```sh
python3 main.py
```

Writes `1024x1024` PNG to `/output/entry.png` (and `output/entry.png`).
Standard library only, no network, deterministic: two runs write identical bytes.
